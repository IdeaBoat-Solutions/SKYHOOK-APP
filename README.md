# Skyhook — Crane Business Management ERP

Centralized ERP for crane operations, workforce, machinery, project-based overtime, attendance,
payroll, EMI and renewal compliance.

> **Current state:** React 19 + Vite SPA backed by a complete Fastify/TypeScript API — the UI talks
> to the server through `src/api/` and `src/data/apiStore.tsx` (no localStorage business data).
> The backend runs on local Postgres by default and can be switched to **Supabase** for database,
> Auth and Storage via `server/.env` (see [docs/11](./docs/11-SUPABASE-SETUP.md)).

The public landing page is shown at `/` before sign-in; it uses the same design tokens as the ERP.

## Run locally

Frontend prototype:

```powershell
bun install
bun run dev      # http://localhost:3000
bun run lint
bun run build
```

Backend (Phase 1 implementation — see [server/README.md](./server/README.md)):

```powershell
docker compose up --build                    # Postgres 16 + API on :3001
# or: cd server; npm install; npm run migrate; npm run seed; npm run dev
cd server; npm run worker                    # outbox + reminder worker (separate process)
cd server; npm test                          # 10 business-rule tests
./scripts/smoke.ps1                          # 12 money-critical API assertions
./scripts/smoke-full.ps1                     # 33 assertions across every module
```

To rebuild the knowledge graph after changes:

```powershell
python -m graphify update . --force
python scripts/enrich_graph.py
python -m graphify tree --graph graphify-out/graph.json --output graphify-out/GRAPH_TREE.html --label "Skyhook ERP"
```
